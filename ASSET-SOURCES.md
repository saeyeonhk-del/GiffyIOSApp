# Asset sources

- Logo, hero and district photos, product and detail images: original Giffy Base44 web component and public Product API URLs, fetched 2026-10-31.
- Inter: https://github.com/google/fonts/tree/main/ofl/inter. License in Giffy/Fonts/inter-OFL.txt.
- Fraunces: https://github.com/google/fonts/tree/main/ofl/fraunces. Regular optical-size-9 instance, renamed internal family Giffy Fraunces. License in Giffy/Fonts/fraunces-OFL.txt.
- Google mark: https://developers.google.com/identity/images/g-logo.png.
- Colours, labels, radii and mobile layout match the web source. Native back navigation, text entry, menus and sheets remain iOS controls.
